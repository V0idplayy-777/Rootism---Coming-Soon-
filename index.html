rootism is an ai coding agent. it is not an api wrapper. i'm training the whole thing myself from zero, which is objectively a terrible financial decision and probably above my pay grade, but fuck it, here we are.

i know how hard this is going to be. i also know there are already heaps of coding agents and i'm not a creative guy, so the differentiation strategy is currently just "hope it doesn't suck".

[01] what this is

a coding agent where the model itself is actually mine. everyone else rents an api, hot-glues twenty python scripts together, and calls it an ecosystem. i want to train my own weights from nothing so that when it shits the bed at 3am, i have nobody to blame but myself.

why rootism? i'm thinking of calling it that because root access sounds cool and i spent about twelve seconds thinking about it before getting back to terminal. if it's awful i'll rebrand right before bankruptcy.
